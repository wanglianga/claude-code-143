# 城市临时用工日结平台

面向商超盘点、会展搭建、仓库分拣、餐饮帮工、保洁突击、活动安保等城市临时用工场景的一体化平台，覆盖 **企业发单 → 工人报名 → 四重考勤 → 保险生效 → 现场事件 → 日结结算 → 申诉仲裁 → 风险沉淀** 全链路。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 18 + Vite + Ant Design 5 + react-router（端口 8080） |
| 后端 | NestJS 10 + TypeORM + JWT（端口 3000，Swagger: `/api/docs`） |
| 数据库 | MySQL 8（utf8mb4，启动自动建表 + 种子数据） |

## 一键启动（Docker Compose）

```bash
docker compose up --build
```

- 前端：http://localhost:8080
- 后端 API：http://localhost:3000/api （文档 http://localhost:3000/api/docs）
- MySQL：localhost:3306（root / root123，库 `daywork`）

首次启动后端自动建表并写入演示数据（四类角色账号、岗位、历史完工/取消/争议记录）。

## 本地开发

```bash
# 1. 准备 MySQL（8.x），创建数据库
mysql -u root -p -e "CREATE DATABASE daywork CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2. 后端（默认读环境变量 DB_HOST/DB_PORT/DB_USER/DB_PASSWORD/DB_NAME，见 server/.env.example）
cd server && npm install
DB_HOST=127.0.0.1 DB_PORT=3306 DB_USER=root DB_PASSWORD=你的密码 npm run build && node dist/main.js
# 或开发模式：npm run start:dev

# 3. 前端（Vite 已配置 /api、/uploads 代理到 3000）
cd web && npm install && npm run dev   # http://localhost:5173
```

## 核心验证方式

### 方式一：自动化端到端脚本（49 项断言）

后端运行中执行：

```bash
bash scripts/e2e-test.sh
```

覆盖：登录 → 未实名拦截 → 实名+签署风险告知 → 保证金试算（低/高风险倍率）→ 发单冻结 → 报名录用派单 → 二维码/地理围栏/人脸三处拦截 → 签到自动确认+保险生效 → 加班/额外搬运事件 → 越权事件拦截 → 签退生成日结单（工时/加班费/保费/服务费逐项核对）→ 企业支付 → 互评 → 申诉取证（签到轨迹/聊天记录）→ 客服补发 → 高风险企业主管确认才生效保险 → 他企主管越权拦截 → **事故后禁止补录保险** → 受伤理赔 → 取消岗位补偿+取消率沉淀 → 风险看板。

### 方式二：页面手动验证

1. **工人**：登录张三 →「岗位市场」报名 →「我的任务」进入任务 → 输入企业端显示的签到码 + 获取定位 + 采集人脸完成签到 → 签退 →「我的结算」查看日结明细 → 对扣款「申诉」（可传现场照片）→「我的保单」查看生效时间/申请理赔。
2. **企业**：登录好又多 →「工作台」充值保证金 →「发布岗位」（右侧实时试算冻结保证金）→「岗位管理」发布 →「岗位详情」审核报名、录用 → 任务详情出示签到二维码、上报加班/扣款事件 →「结算管理」确认支付（保证金划扣）。
3. **主管**：登录主管账号 →「现场任务」→ 确认到岗（高风险岗位必需）、上报现场事件。
4. **客服**：登录客服 →「申诉工单」→「取证」查看签到轨迹、主管确认、现场照片、聊天记录 → 裁决补发/维持/升级仲裁；「风险看板」查看企业风险画像与行业风险沉淀。

## 关键业务规则

- **考勤四重校验**：签到二维码 + 500 米地理围栏 + 人脸采集 + 现场主管确认；低风险岗位前三项通过即自动确认，高风险岗位/高风险企业必须主管现场确认。
- **保险不可补录**：保单在实际到岗确认时签发，生效时间 = 确认时间；任务已上报受伤事件后禁止补录保单；理赔要求受伤事件发生在保单生效之后。
- **日结公式**：应发 = 基础工时×时薪 + 加班时长×加班时薪 + 餐补（满 4h）− 迟到扣款 − 其他扣款；工人实收 = 应发 − 保费；企业另付平台服务费 5%；全部从发单时冻结的预付保证金划扣，剩余完结退回。
- **风险沉淀**：企业取消率/争议率 ≥15% 判高风险（保证金倍率 ×2、考勤强制主管确认），≥5% 中风险（×1.5）；取消岗位按预估日薪 30% 补偿已录用工人；行业维度统计工伤/争议/取消形成岗位风险分。
- **申诉仲裁**：申诉冻结结算支付，客服基于签到轨迹、主管确认、现场照片、聊天记录裁决补发（企业保证金赔付）/维持/升级仲裁，结果计入企业争议率。
